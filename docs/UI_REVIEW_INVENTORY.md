# UI review coverage inventory

Companion to the [UI review ledger](UI_REVIEW_LEDGER.md). Baseline: `45245daf360d0bd352f28da39b5ddec6978931c1`, inspected 2026-11-08.

## How to read coverage

Every file below received a source review of its authored markup, styling and component behavior. Named view functions and aliases are listed to make subcomponents traceable; constants and third-party internals are not separate product screens. Inline render functions belong to their parent row. A source review does not prove every prop combination, theme or platform.

`Native` means the real packaged macOS application. `Fixture` means unchanged public web components rendered without the broken root auth dependency. `Library only` means no reachable product call site was found in desktop/web source, so there is no live screen to inspect. A finding linked to an unused module is library follow-up, not evidence that users can encounter it today.
